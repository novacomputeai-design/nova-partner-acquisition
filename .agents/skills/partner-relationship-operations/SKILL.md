# partner-relationship-operations

Review-stage Nova instruction — NOT a license to send, purchase services or access private data. Apply `AGENTS.md` and `docs/operating-contract.md`. Maintain original evidence sources and checked dates. Missing required data => UNKNOWN / HOLD.

## Procedure
1. Use authorized PRIVATE account, person, opportunity, approval, message, activity and suppression records; never place them in this public repo. A local answer is not durable persistence.
2. Before sending, require explicit R0/Gate A and separate founder DISPATCH authorization tied to exact sender, recipient, subject, body and attachments; verify professional route, current role, history, sender compliance and opt-out status.
3. This review-stage skill does NOT itself send. A separately authorized mail connector action in approved runtime is required. Record operation key and message fingerprint, then confirm actual provider result and read-back.
4. Provider timeout => SEND_UNCERTAIN and no unattended retry until provider Sent Items / message id checked. SENT is not delivery or reply.
5. Record email responses as INTERESTED, REFERRAL, REQUEST_INFORMATION, NO_CURRENT_NEED, NOT_INTERESTED, OPT_OUT, BOUNCE, OUT_OF_OFFICE, AMBIGUOUS, NO_REPLY_OBSERVED.
6. Immediately honor opt-outs with correct person/organization scope, preserve previous events and avoid alternate-person evasion. Bounce blocks invalid route, not necessarily whole company.
7. Suggest one founder-reviewed follow-up after 5–7 business days and a second after 7–10 more only when appropriate. Never silently enroll an automatic sequence.
8. Record replies/meetings/requirements/deals only from actual observed evidence, not anticipated outcomes.

## Output
A concise evidence-based decision, role-specific record updates and one recommended next action. Do not claim research, database writes or tool usage that did not occur.
